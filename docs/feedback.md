# Pactra External Tester Feedback Form & Log

> **Pactra Preprod MVP Tester Feedback Channel**
>
> *"Give an agent a goal and bounded economic authority — not your wallet."*

We appreciate community members, hackathon judges, and fellow Midnight developers testing the **Pactra Preprod MVP**. Please use this template to report findings, suggestions, or edge cases.

---

## 1. How to Submit Feedback

You can submit feedback via:
1. **GitHub Issue:** [Create a New Issue](https://github.com/Kalpesh-ops/agent-commerce-midnight/issues/new) using the format below.
2. **Pull Request:** Add your entry directly to the Tester Log table in Section 3 of this document.

---

## 2. Structured Feedback Template

```markdown
### Tester Feedback Submission

- **Tester Name / Handle:** (e.g., @midnight_builder)
- **Date Tested:** YYYY-MM-DD
- **Environment Tested:**
  - Browser: (e.g., Chrome 128 / Brave 1.70)
  - OS: (Windows / macOS / Linux)
  - Lace Wallet Version: (e.g., 1.x Preprod)
- **Areas Evaluated:**
  - [ ] Wallet Connection & Rejection handling
  - [ ] First-Time Onboarding Modal
  - [ ] 9-Step Guided Compute Walkthrough
  - [ ] Multi-Service Marketplace Discovery
  - [ ] Privacy Boundary Inspector & Commitment Simulator
  - [ ] Threshold Arbitration Board
  - [ ] Live Midnight Contract Deployment & Indexer Sync
- **What Worked Well:**
  - (Describe smooth interactions or clear explanations)
- **Points of Confusion / Friction:**
  - (Describe any UX or architectural steps that felt unclear)
- **Bugs Encountered:**
  - (Include console errors or unexpected behaviors)
- **Suggestions for Level 5 / Mainnet:**
  - (Ideas for future capabilities)
```
